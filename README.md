# C Programming Projects

A collection of beginner to intermediate C programming projects created to practice programming concepts, problem-solving, and standard C programming techniques.

## 📂 Projects Included

### 1. Calculator
A simple command-line calculator that performs basic arithmetic operations.
- Addition
- Subtraction
- Multiplication
- Division

**File:** `calculator.c`

---

### 2. Print Time
A basic program that demonstrates time formatting and printing.

**File:** `printtime.c`

---

### 3. Digital Clock
A digital clock implemented using C.

**Features**
- Displays current time


**File:** `digital_clock.c`

---

### 4. Real-Time Clock
An improved version of the digital clock with real-time updates.

**Features**
- Displays current system time
- Refreshes every second

**File:** `realtimeclock.c`

---

## 🛠️ Technologies Used

## 🚀 How to Run

### Compile

```bash
gcc filename.c -o output
```

### Run

#### Windows

```bash
output.exe
```

#### Linux/macOS

```bash
./output
```

Example:

```bash
gcc calculator.c -o calculator
./calculator
```
